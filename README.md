## What it does

- **One tap** on a favourite drink logs it. Undo if you didn't mean it.
- **How much caffeine is in your body right now**, and a curve of the whole day and night.
- **"Espresso OK until 6:40 PM"**: the latest time you can have one more and still sleep
  well, from your bedtime and what you've had so far.
- **Sleep cycles**, like a sleep calculator: wake up at 7:00, go to bed at 11:15 PM (or
  9:45). Or go to bed now and see when to wake up. With the caffeine you'll still have at
  each time, and a button that sets the alarm on your clock app.
- **Today against the daily maximum**, and a history of the last 14 and 30 days.
- 21 common drinks to start with, all editable.
- **How it's calculated**, in Settings: every number explained, with the studies behind it.

In English and Spanish, light and dark. For healthy adults: the numbers are estimates from
published research, not medical advice.

## Privacy

Everything is stored encrypted on your phone and the app has no internet permission. No
accounts, no ads, no tracking.

## Install

Download `catffeine.apk` from
[the latest release](https://github.com/apvwbm/catffeine/releases/latest) and open it on your
phone. To update, install the new one on top: your data is kept.

<details>
<summary>For developers</summary>
<br />

Expo SDK 57 · React Native · TypeScript · SQLite encrypted with SQLCipher.

```bash
npm install && npm start   # Expo Go (no encryption)
npm run verifica           # logic tests
npm run apk                # APK on the Desktop (Windows + Android SDK)
```

</details>
